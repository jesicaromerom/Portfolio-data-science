# Statistics

## Inferential

01_quality_and_imputation.py: Métodos de imputación (KNN, imputación iterativa MICE) y justificación matemática de cuándo no imputar.

02_robust_statistics.py: Comparación entre estadísticas clásicas (media, desviación estándar) y estadísticas robustas (mediana, MAD — Median Absolute Deviation, media recortada/winsorizada) en presencia de outliers.

03_multivariate_correlations.py: Matriz de correlación de Pearson, Spearman (rango no lineal) y Kendall Tau, junto con detección de colinealidad mediante el Factor de Inflación de la Varianza (VIF).

## Noninferential

power_analysis.py: Cálculo a priori del tamaño muestral necesario según el tamaño del efecto ($Effect\ Size$), error Tipo I ($\alpha$) y potencia estadística ($1-\beta$).

assumption_checks.py: Pruebas formales de normalidad ($Shapiro\text{-}Wilk$, $D'Agostino\text{-}Pearson$) y homocedasticidad ($Levene$, $Bartlett$).

hypothesis_testing.py:Caso paramétrico: Test t de Student / ANOVA con correcciones de pruebas múltiples (Bonferroni, Holm-Bonferroni, FDR de Benjamini-Hochberg).Caso no paramétrico: Mann-Whitney U / Kruskal-Wallis cuando fallan los supuestos de normalidad.

mle_fitting.py: Ajuste de distribuciones teóricas (Gamma, Weibull, Log-Normal) mediante Estimación de Máxima Verosimilitud (MLE) y evaluación con pruebas de bondad de ajuste ($Kolmogorov\text{-}Smirnov$, $Anderson\text{-}Darling$).

bootstrap_intervals.py: Construcción de Intervalos de Confianza no paramétricos mediante métodos Bootstrap (Percentil y BCa — Bias-Corrected and Accelerated) para métricas complejas como el percentil 95 o la razón de varianzas.
